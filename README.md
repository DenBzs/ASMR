# ASMR Studio (SillyTavern 확장)

채팅 메시지의 ASMR 대본을 ElevenLabs로 **대사(TTS) + 효과음(Sound Effects)** 을 따로 뽑아 한 트랙으로 믹스합니다.
효과음이 대사와 동등한 줄이라서 효과음만 연속으로 나오거나, 목소리와 동시에 겹치거나, 배경음을 깔 수 있습니다.
자막은 번역문으로 달고 음성은 원문으로 만듭니다. 결과는 WAV / MP3 / SRT / 자막 영상(webm)으로 저장합니다.

## 설치

1. 이 폴더를 `SillyTavern/public/scripts/extensions/third-party/ST-ASMR-Studio` 에 둡니다. (폴더 이름은 자유, 안의 파일 구조는 그대로)
   - 사용자별 폴더를 쓰는 설치라면 `data/<사용자>/extensions/ST-ASMR-Studio`
2. ST를 새로고침합니다. 확장 패널에 **ASMR Studio** 가 생깁니다.
3. 설정 열기 → **ElevenLabs API 키** 입력 (효과음에 필수), **목소리 불러오기** → 기본 목소리 선택.

키는 이 브라우저의 localStorage에만 저장됩니다(ST 설정 파일에는 들어가지 않습니다).

## 쓰는 법

- 각 메시지의 버튼 줄에 생긴 🎧 버튼을 누르거나, 설정의 **마지막 메시지로 스튜디오 열기**.
- 대본이 이미 아래 형식이면 바로 **생성 · 믹스**.
- 일반 서술이면 **LLM으로 연출 변환** 을 눌러 형식으로 바꾼 뒤(되돌리기 가능) 확인하고 **생성 · 믹스**.
- 처음부터 AI가 이 형식으로 쓰게 하려면 **작성 가이드 복사** → 프리셋/작가의 노트에 붙여 넣기.

## 대본 형식

```
((~ quiet bedroom room tone))                      배경음: 다음 ~ 까지 뒤에서 계속
((@L cotton sheets rustling, close mic))           효과음: 끝난 뒤 다음 줄
((+ @R *0.7 #3 wooden bed frame creak))            + : 다음 줄과 동시에
[whispers] Come here. | 이리 와.                    대사 | 자막용 번역
((pause 2))                                        2초 쉼
SOREN: [softly] Lie down on your side. | 옆으로 누워.  화자 지정
```

| 기호 | 의미 |
|---|---|
| `(( ))` | 효과음 (기호는 설정에서 변경 가능) |
| `+` | 다음 대사/효과음과 동시에 재생 |
| `~` | 배경음. 다음 `~` 줄 또는 끝까지 이어짐 (기본 생성 길이 20초를 반복) |
| `@L` `@R` `@C` `@-0.6` | 좌 / 우 / 중앙 / 숫자(-1~1) 패닝 |
| `*0.6` | 볼륨 배수 |
| `#4` | 효과음 길이(초, 0.5~30). 배경음은 재생 길이 |
| ` \| ` | 대사 뒤에 번역(자막용). 효과음에 붙이면 효과음 자막 |

- 옵션(`@ * #`)은 기호 바로 뒤에 두거나 문장 맨 끝에 둬도 됩니다.
- 대사 앞뒤의 `[whispers]` 같은 **짧은 대괄호는 목소리 연기 태그**(v4/v3 모델)로 TTS에 그대로 전달됩니다.
- 예전 대본처럼 **줄 전체가 긴 `[묘사]`** 면(기본 4단어 이상) 효과음으로 처리합니다. (설정에서 끌 수 있음)
- `*지문*` 줄은 읽지 않습니다. 화자는 `ALL-CAPS` 단독 줄 또는 `NAME: 대사`.
- 효과음 프롬프트는 영어로, 한 번에 한 소리씩, 짧고 구체적으로 쓰면 결과가 좋습니다.

## 비용과 캐시

- 대사와 효과음 모두 한 번 만든 것은 브라우저에 캐시되어, 같은 대본을 다시 믹스해도 크레딧이 들지 않습니다.
- 마음에 안 드는 소리는 해당 줄의 문구를 조금 바꾸거나 **캐시 무시**를 체크하고 다시 생성하세요.
- 같은 효과음 묘사가 여러 번 나오면 기본은 매번 새로 만들어 변화를 줍니다(설정에서 재사용 가능).
- 동시 생성 수는 ElevenLabs 요금제 한도에 맞춰 조절하세요(기본 2).

## 한계 / 알아둘 점

- 영상은 브라우저에서 **재생 시간만큼 실시간으로 녹화**합니다(webm). 그동안 탭을 보이는 상태로 두세요.
- 긴 대본은 믹싱 메모리를 많이 씁니다. 20분 넘는 결과는 샘플레이트를 낮추거나 나눠서 만드세요.
- 음성 경로 "ST 서버 경유"는 ST의 ElevenLabs 키를 쓰는 방식이고 ST 1.15 이상이 필요합니다. 안 되면 "직접 호출"로 바꾸고 키를 넣으세요.
- 효과음은 ElevenLabs로 브라우저에서 직접 호출합니다.
- MP3 변환은 처음 한 번 lamejs를 CDN에서 불러옵니다(실패하면 WAV로 저장).

## 개발

- `lib/parser.js` 대본 → 이벤트, `lib/timeline.js` 배치, `lib/mixer.js` 믹스·인코딩, `lib/eleven.js` API, `lib/export.js` 자막·영상, `lib/prompts.js` 프롬프트.
- 순수 로직 테스트: `npm test` (Node 18+).
